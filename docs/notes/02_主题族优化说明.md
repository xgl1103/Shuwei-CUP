# 主题族优化说明

## 1. 调整原因

前期主题族中出现过 `统计报表与基本情况类`、`工作总结与调研汇报类`、`综合文书与其他类` 等标签。它们更像文种、格式或材料形态，不是最终想要的内容主题。

当前主题族优化方向已经调整为“内容主题分类”：最终类别优先回答“文件主要讨论什么领域”，而不是“文件长得像什么文种”。

## 2. 当前主方案

当前主链路已经固定为：

```text
k = 160
```

含义：

- 问题一先把 dataset1 中可用历史文本切成 160 个细粒度主题原型；
- `05_refine_topic_families.py` 再把这些主题原型映射到可解释内容主题；
- 问题二使用这些主题原型和内容主题规则，对 dataset2 与 dataset3 做相似度归类；
- 问题三基于分类边界、风险和必要性给出人工复核优先级。

之所以选 `k=160`，是因为它在 `k=90/120/160/200/240/288` 消融实验中取得了相对均衡的结果：比 `k=90` 更细，比 `k=240/288` 更不碎。完整对照见 `notes/05_k消融实验与推荐方案.md`。

## 3. 当前主题口径

当前内容主题规则包括但不限于：

- `教育科研与学术文献类`
- `综合统计指标类`
- `企业投资与房地产类`
- `财政金融与宏观经济类`
- `地区民生与收入消费类`
- `人口就业与社会保障类`
- `工业交通与能源通信类`
- `资源环境与城市建设类`
- `政府治理与公共管理类`
- `科技专利与标准规范类`
- `医药卫生与药品类`
- `文化旅游与居民消费类`
- `对外贸易与国际经济类`
- `农业农村与土地资源类`
- `综合内容待判别类`

这些主题不是人工预设后直接分类，而是由“历史主题原型 + 内容规则校准 + 新文本相似度映射”共同形成。

## 5. 已处理的问题

1. 数据集3已经按 Excel 行展开，不再把整个 Excel 当成一个文件分类。
2. 文本降噪已落地，已过滤网页导航、版权、URL、登录注册、重复模板行等噪声。
3. 教育科研类误吸已做规则修正，政府治理、统计督察、项目建设等文本不会仅因“研究、项目、工作”等泛词被吸入教育类。
4. 复核必要性打分已修正，普通政策信号不再直接把大量样本推到高优先级。
5. 已完成 k 值消融实验，并把主输出目录切换为 `k=160` 版本。
6. 已完成问题二边界优化：同一主题原型家族内部竞争不再直接判为多类；证据充分的轻微跨类竞争由规则消歧后输出唯一类，同时保留复核原因。
