# 问题三解决方案

## 1. 任务目标

问题三不是再做一次分类，而是把问题二的结果转成“人工复核优先级”。

输入主要来自：

- `classification_results.csv`
- `review_queue.csv`
- `parsed_documents.jsonl`
- `document_features.csv`
- 数据集4：业务规则与资源约束表

输出主要是：

- `review_priority_results.csv`
- `review_priority_summary.csv`
- `resource_plan.csv`
- `resource_allocations.csv`

## 2. 三个打分维度

### 2.1 错分风险

直接沿用问题二中的边界信息和风险信息，包括：

- `risk_score`
- `risk_level`
- `classification_status`

这是优先级中最重要的一项。

### 2.2 紧急程度

从正文、标题、时间字段和关键字中提取：

- 紧急
- 立即
- 限期
- 截止
- 今天
- 明天
- 本周
- 本月

再结合日期表达式，判断时间压力。

### 2.3 复核必要性

从内容重要性和金额信息判断：

- 资金、预算、决算、经费、补贴、采购、招标
- 金额数字 + 货币单位
- 审批、核准、备案、合同、标准、药品等高敏感词

## 3. 综合优先级

采用 AHP 确定三项权重：

- 错分风险
- 复核必要性
- 紧急程度

然后合成为：

```text
priority_score = w1 * 风险 + w2 * 必要性 + w3 * 紧急程度
```

并划分为：

- `high`
- `medium`
- `low`

## 4. 资源约束处理

数据集4给出三种场景约束，包括：

- 每日可用人工工时
- 自动归档能力上限
- 人工复核能力上限

当前做法不是简单平均分配，而是按优先级和收益密度进行贪心调度：

1. 先选高优先级样本
2. 再选中优先级样本
3. 剩余低优先级样本进入自动归档
4. 超出约束的样本进入延期复核队列
