# 数维杯 B 题可视化复核工作台开发说明

本文档面向后续开发 Agent，用于实现一个可运行的“多源异构文件识别与人工复核工作台”。请优先保证功能闭环、数据真实可读、界面可截图展示，不要做营销页或空的大屏。

## 1. 项目定位

本界面服务于 B 题三个问题的落地展示：

- 问题一：展示历史文件主题体系、主题簇、关键词和代表文档。
- 问题二：展示数据集 2 和数据集 3 的新文件归类结果、置信度、候选类别和可解释证据。
- 问题三：展示高/中/低复核优先级、人工复核队列、资源约束场景 S1/S2/S3 下的分配结果。

核心业务链路：

```text
多源文件解析 -> 历史主题体系 -> 新数据归类 -> 风险分级 -> 人工复核 -> 操作留痕
```

当前数据已经跑通：

- `dataset1 = 3396` 条，用于问题一主题发现。
- `dataset2 = 1001` 条，用于问题二新文件归类。
- `dataset3 = 3518` 条，已按 Excel 行展开为 `dataset3:N00001` 等记录，用于问题二新文件归类。
- 问题二分类总量 `4519` 条。
- 问题三优先级总量 `4519` 条。

当前主方案已经固定为 `k=160` 主题原型：

- 问题一：`selected = 3133`，覆盖率 `0.923`，主题原型数 `160`。
- 问题二：`assigned = 3159`，`multi_class = 1294`，`unclassifiable = 66`。
- 问题三：`high = 164`，`medium = 1932`，`low = 2423`。
- 消融实验结果见 `outputs/experiments/k_ablation_summary.csv` 和 `notes/05_k消融实验与推荐方案.md`。

## 5. 数据加载与合并逻辑

前端建议生成三个核心集合：

### 5.1 `parsedDocs`

来自 `parsed_documents_index.csv`，用 `doc_id` 作为 key。

### 5.2 `classificationRows`

来自 `classification_results.csv`，代表问题二全部新数据分类结果。

合并规则：

```ts
classificationViewRow = {
  ...classificationRow,
  ...parsedDocMap[classificationRow.doc_id],
}
```

注意：分类表本身已有 `title`、`file_name` 等字段，冲突时优先使用分类表字段。

### 5.3 `priorityRows`

来自 `review_priority_results.csv`，代表问题三全部复核优先级结果。

合并规则：

```ts
priorityViewRow = {
  ...classificationMap[doc_id],
  ...priorityRow,
}
```

优先级表字段优先级更高，因为它包含最终复核推荐。

## 8. 视觉与交互规范

### 8.1 风格

采用“企业级文档治理中台”风格：

- 高信息密度
- 表格优先
- 轻量图表辅助
- 状态标签清晰
- 专业、克制、可截图

不要做：

- 营销 landing page
- 炫酷但不可操作的大屏
- 过多渐变、光球、漂浮装饰
- 卡片套卡片

### 8.2 布局

推荐：

```text
顶部栏：项目名、搜索、数据刷新、导出按钮
左侧栏：总览 / 解析监控 / 主题发现 / 分类结果 / 待复核队列 / 资源场景
主区域：表格和图表
右侧：详情抽屉
```

桌面优先，设计宽度参考 `1440px`。

### 8.3 颜色

推荐浅色专业风：

- 背景：`#f6f8fb`
- 面板：`#ffffff`
- 主文字：`#172033`
- 次级文字：`#64748b`
- 主色：`#2563eb`
- 辅色：`#0f766e`
- 高风险：`#dc2626`
- 中风险：`#f59e0b`
- 低风险：`#16a34a`

### 8.4 状态标签

建议映射：

```text
assigned -> 已归类 / 绿色
multi_class -> 多类待判 / 橙色
unclassifiable -> 无法归类 / 红色
auto_archive -> 自动归档 / 绿色
review_if_capacity -> 容量允许复核 / 蓝色
must_review -> 必须复核 / 红色
high -> 高 / 红色
medium -> 中 / 橙色
low -> 低 / 绿色
```

### 8.5 数字展示

所有分数建议保留 3 位小数：

```ts
formatScore = (value) => Number(value || 0).toFixed(3)
```

百分比：

```ts
formatPercent = (value) => `${(Number(value || 0) * 100).toFixed(1)}%`
```
